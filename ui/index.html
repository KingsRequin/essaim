Preset automatique

Essaim change tout seul de preset selon tes règles (artiste, titre, tempo…), l'application au premier plan ou l'heure. Quand plus aucune règle ne s'applique, tes réglages d'avant reviennent.

Raccourcis clavier
Ctrl + Alt + →preset suivant Ctrl + Alt + ←preset précédent Ctrl + Alt + Ppause

Ils marchent partout dans Windows, sans surveiller le clavier (pas de hook) : Windows prévient seulement Essaim quand ces touches sont pressées.

Si … alors …prioritaire

Clés : artiste, titre (morceau qui joue), appli, bpm (tempo des kicks), heure. Opérateurs : =  !=  ~ (contient)  <  >  <=  >=. Plusieurs conditions : « et ». Exemple : bpm > 140 et heure >= 20:00.

Jeux installés sur ce PC
Un preset enregistré garde le jeu en place à ce moment-là ; cette option le remet quand tu choisis le preset.
Chargement des curseurs…
Un clic installe le jeu, comme le panneau de la souris de Windows. Pour en ajouter un : clic droit sur le fichier .inf d'un pack, puis Installer.
Trajet d'une image

Les comètes suivent le contour d'une image : un logo, une silhouette, une icône (une image à fond transparent marche le mieux), ou d'un texte, d'un emoji. Tu peux aussi glisser une image sur la fenêtre.
